# sysml-requirement-diagram-builder

Generate an audit-ready SysML Requirement Diagram authoring workbook per OMG SysML 1.6 and 2.0 capturing requirement blocks with id and text, derive, satisfy, verify, refine, copy, and trace relationships, requirement containment hierarchy, and rationale annotations for systems engineering requirements traceability.

**Use this skill whenever the user mentions SysML requirement diagram, derive requirement, satisfy requirement, verify requirement, refine requirement, or requirements containment hierarchy.**

## Generates
- 10-tab audit-ready xlsx workbook
- Requirement blocks with ID and text
- Containment hierarchy (parent-child relationships)
- Derive, Satisfy, Verify, Refine relationships
- Rationale and annotation support
- Traceability matrix
- Validation rules per SysML 1.6/2.0

## Tabs
0_Title, 1_Document_Control, 2_Requirement_Set_Identity, 3_Requirement_Catalog, 4_Containment_Hierarchy, 5_Derive_Relationships, 6_Satisfy_Relationships, 7_Verify_Relationships, 8_Refine_Copy_Relationships, 9_References

## Input
- Requirements with IDs and descriptive text
- Functional, non-functional, design requirements
- Allocation and satisfaction targets
- Verification methods

## Output
- Cameo/Rhapsody/Capella import ready
- Complete traceability matrix
- Hierarchy validation
- Orphan requirement detection
