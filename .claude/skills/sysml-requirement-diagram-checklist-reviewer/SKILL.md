# sysml-requirement-diagram-checklist-reviewer

Run a confirmation review on any SysML requirement diagram xlsx, probing for well-formedness, hierarchy integrity, relationship validity, and traceability completeness per OMG SysML 1.6 and 2.0.

**Use this skill whenever the user provides a completed SysML requirement diagram xlsx and requests checklist validation or traceability audit.**

## Runs
- 25 canonical checks across 6 confirmation review tabs
- Requirement ID uniqueness and format
- Containment hierarchy tree validation
- Satisfy/verify/derive relationship targets
- Orphan requirement detection
- Traceability coverage

## Output
- 7-tab checklist xlsx with Summary, Findings
- Dashboard with KPIs (ID Conflicts, Orphans, Coverage %)
- Per-section findings and confidence levels
