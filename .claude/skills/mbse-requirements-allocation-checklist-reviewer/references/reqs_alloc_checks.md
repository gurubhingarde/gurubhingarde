# Requirements Allocation Checks

## CR01: Requirements Populated

5+ requirements needed to exercise the decomposition and allocation structure.

**Finding**: Count requirements in Catalog
**Action**: Add requirements across hierarchy

## CR02: Hierarchical Decomposition

System, sub-system, and component requirements needed to document full decomposition.

**Finding**: Count by level
**Action**: Create derived requirements at each level

## CR03: All Requirements Allocated

Every requirement must map to at least one design element (function, component, etc.).

**Finding**: Compare Catalog vs Allocation Matrix count
**Action**: Allocate orphan requirements

## CR04-CR06: Relationships

Satisfy, Derive, Verify tabs document the traceability paths and verification methods.

**Finding**: Check tab presence
**Action**: Create tabs and populate relationships
