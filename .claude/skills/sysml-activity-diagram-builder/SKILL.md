# sysml-activity-diagram-builder

Generate an audit-ready SysML Activity Diagram authoring workbook per OMG SysML 1.6 and 2.0 capturing activities, actions, control flows, object flows, decision and merge nodes, fork and join nodes, swim-lanes, pins, and parameter sets for behavioral modeling of system functions and use case realizations.

**Use this skill whenever the user mentions SysML activity diagram, control flow, object flow, swim-lane, decision node, fork node, or behavioral activity model.**

## Generates
- 11-tab audit-ready xlsx workbook
- Activities with action nodes
- Control flow and object flow topology
- Decision/merge and fork/join nodes
- Swim-lane assignments
- Pin and parameter definitions
- Validation rules per SysML 1.6/2.0

## Tabs
0_Title, 1_Document_Control, 2_Activity_Header, 3_Action_Catalog, 4_Control_Flow_Catalog, 5_Object_Flow_Catalog, 6_Decision_Merge_Nodes, 7_Fork_Join_Nodes, 8_Swim_Lanes, 9_Pins_Parameters, 10_References

## Input
- Activity structure and action hierarchy
- Control and data flow connections
- Swim-lane allocations
- Decision guards and fork/join conditions

## Output
- Cameo/Rhapsody/Capella import ready
- Complete flow topology
- Balanced fork/join nodes
- Proper action allocation
