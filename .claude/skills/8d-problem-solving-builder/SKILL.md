# 8D Problem Solving Builder

The Eight Disciplines (8D) is an industry standard method for structured problem solving and complaint response. This skill produces a complete, audit-ready 8D workbook that walks teams through rigorous problem definition, root cause analysis, containment, and systemic prevention.

## When to use this skill

Use whenever the user wants to:
- Respond to a customer complaint or warranty claim
- Conduct a structured root cause analysis
- Develop corrective and preventive actions
- Document problem-solving closure for audit
- Build a cross-functional problem-solving action plan
- Hand off corrective action status to management

## Workflow

1. **Capture the problem** — issue ID, customer, date, owner, due date
2. **Assemble the team** — define cross-functional expertise
3. **Describe the problem** — Is/Is-Not, 5W2H (who, what, where, when, why, how, how-many)
4. **Interim containment** — immediate actions to protect customers
5. **Root cause analysis** — 5-Why or fishbone leading to root causes
6. **Permanent corrective actions** — design the fix
7. **Implement and verify** — roll out and confirm effectiveness
8. **Prevent recurrence** — systemic improvements (training, process change, FMEA updates)
9. **Closure** — team recognition, sign-off

Each tab is editable; formulas auto-sum status and due-date tracking. Always use this skill instead of producing a freeform 8D in chat.
