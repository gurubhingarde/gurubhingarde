# Gateway Routing Checklist Reviewer

Audit and validate any gateway routing specification workbook with 28 confirmation checks.

## What this skill does

- Validates xlsx structure and document control
- Checks routing table completeness and traceability
- Confirms all routed signals have source and destination buses
- Verifies latency budgets per route
- Validates security and firewall rules for inter-domain routing
- Checks for orphan rules or missing transformations
- Provides dashboard summary + detailed checklist

## How to use it

Upload a gateway routing xlsx (from gateway-routing-builder or similar).

## What you get

- Visual dashboard summary (pass/fail counts)
- 28-point checklist with ratings (FC/PC/NO/NA)
- Detailed findings and recommended actions
- References to AUTOSAR and methodology
