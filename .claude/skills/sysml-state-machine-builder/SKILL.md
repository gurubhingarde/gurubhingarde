# sysml-state-machine-builder

Generate an audit-ready SysML State Machine Diagram authoring workbook per OMG SysML 1.6 and 2.0 capturing state machines, simple and composite states, transitions with triggers and guards and effects, entry and exit and do behaviors, regions, history pseudo-states, and submachine references for behavioral modeling of system modes and lifecycles.

**Use this skill whenever the user mentions SysML state machine, state diagram, transition guard, composite state, region, history pseudo-state, or behavioral state model.**

## Generates
- 11-tab audit-ready xlsx workbook
- Simple and composite states
- Transitions with triggers, guards, effects
- Entry/exit/do behaviors
- Pseudo-states (initial, final, history, choice, junction)
- Region definitions
- Validation rules per SysML 1.6/2.0

## Tabs
0_Title, 1_Document_Control, 2_State_Machine_Header, 3_State_Catalog, 4_Region_Catalog, 5_Transition_Catalog, 6_Entry_Exit_Do_Behaviors, 7_Pseudo_States, 8_Internal_Activities, 9_Validation_Rules, 10_References

## Input
- State definitions and hierarchy
- Transition triggers, guards, and effects
- Behavior assignments
- Region and orthogonal regions

## Output
- Cameo/Rhapsody/Capella import ready
- Complete state topology
- Balanced history pseudo-states
- Proper guard and effect semantics
