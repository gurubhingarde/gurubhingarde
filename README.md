# Puff the Candles

A birthday-candle game for toddlers. Blow on the phone (or tap/swipe the flames) to put the candles out, then enjoy confetti and the Happy Birthday tune.

- No ads, no accounts, nothing leaves the phone. The microphone is only used to hear blowing, and it ignores talking and music.
- Grown-up controls at the top: number of candles (1–6), mic on/off, music on/off.

## Get the APK without installing anything
1. Upload this folder to a GitHub repository (including the hidden `.github` folder).
2. Open the repo's **Actions** tab and wait for **Build APK** to finish (about 5 minutes).
3. Open the finished run and download **PuffTheCandles-apk**. Unzip it to get `app-debug.apk`.
4. Copy it to the phone, open it, and allow "Install unknown apps" when asked.

## Or build with Android Studio
Open this folder in Android Studio, wait for Gradle sync, then press Run (or Build > Build APK(s)).
