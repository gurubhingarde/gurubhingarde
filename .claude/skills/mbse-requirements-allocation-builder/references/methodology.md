# MBSE Requirements Allocation Methodology

## Requirement Levels

Requirements organized in hierarchy:
- **Stakeholder Requirements**: Capture user needs and expectations
- **System Requirements**: What the system must do to satisfy stakeholders
- **Sub-system Requirements**: Decomposition of system requirements
- **Component Requirements**: Detailed requirements for individual components

## Allocation

Mapping of requirements to model elements:
- **Satisfy**: Requirement addressed by a system/component function
- **Derive**: Lower-level requirement derived from higher-level
- **Verify**: Method or test that confirms requirement satisfaction
- **Refine**: Constraint or clarification of a parent requirement

## Traceability

Coverage ensures:
- Each requirement allocated to at least one element
- Each element satisfies at least one requirement
- Derivation chains are consistent
- Verification methods are defined
