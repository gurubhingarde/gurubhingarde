# 5-Why Builder

The 5-Why method is a simple, rigorous approach to root cause analysis. By asking "Why?" repeatedly (typically 5 levels deep), teams drill from observed symptom to systemic root cause. This skill produces a complete, audit-ready 5-Why workbook with hierarchical tree visualization, evidence capture, and corrective action tracking.

## When to use this skill

Use whenever the user wants to:
- Perform a quick, structured root cause analysis
- Identify and document the "why" chain behind a problem
- Support corrective action with evidence
- Conduct a problem tree analysis with multiple branches
- Drive continuous improvement from field issues

## Workflow

1. **Problem statement** — clear, measurable description of what happened
2. **5-Why tree** — hierarchical drilling: Why 1 → Why 2 → ... → Why 5; multiple branches allowed
3. **Root causes identified** — consolidate all branches to candidate root causes
4. **Evidence per root cause** — supporting data, observation, or measurement
5. **Corrective actions** — action per root cause with owner, due date, verification
6. **Verification of effectiveness** — post-action check: baseline, target, actual

Each tab editable; summary status auto-calculated. Always use this skill instead of producing freeform 5-Why in chat.
