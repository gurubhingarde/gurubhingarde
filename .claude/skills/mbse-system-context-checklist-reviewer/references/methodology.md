# System Context Checklist Methodology

## Purpose

Confirm system context workbook is complete and ready for operational analysis layer population in ARCADIA/MagicGrid/STRATA modeling.

## Check Categories

1. **Structure**: Tabs, document control, system identification
2. **Boundary**: Clear scope definition, environment
3. **Actors**: Complete inventory by type
4. **Interfaces**: Every actor has defined interfaces
5. **Use Cases**: Primary/secondary actors, flows
6. **Stakeholder Needs**: Captured and prioritized
7. **Scenarios**: Multiple contexts, consistency

## Workflow

1. Define system and boundary
2. Identify all actors (human, system, environmental)
3. Document interfaces for each actor
4. Write use cases from actor perspective
5. Capture operational scenarios
6. Record stakeholder needs
7. Run checklist to verify completeness
8. Resolve gaps before operational analysis
