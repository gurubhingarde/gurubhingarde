# Fishbone Builder

The Ishikawa (fishbone) diagram organizes causes into categories (typically 6Ms: Manpower, Methods, Machines, Materials, Measurement, Mother Nature; or 4Ps for service). This skill produces a complete, audit-ready fishbone workbook with structured cause collection per category, evidence tracking, and optional Mermaid diagram for visualization.

## When to use this skill

Use whenever the user wants to:
- Perform a structured cause-and-effect analysis
- Organize causes by domain (people, process, equipment, materials, measurement, environment)
- Build a fishbone diagram for team brainstorming
- Document and categorize root causes systematically
- Generate a visual fishbone diagram for presentations

## Workflow

1. **Effect statement** — clear problem being analyzed
2. **Cause categories** — 6Ms (manufacturing) or 4Ps (service) framework
3. **Contributing causes per category** — specific causes in each domain
4. **Evidence and rationale** — support each cause with observation
5. **Mermaid diagram** — optional auto-generated fishbone visualization for chat display

Each tab editable; category summaries auto-calculated. Always use this skill instead of producing freeform fishbone in chat.
