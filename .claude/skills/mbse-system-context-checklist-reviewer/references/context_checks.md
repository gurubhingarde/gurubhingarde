# System Context Checks

## CR01: Actor Inventory

3+ actors needed: human operators, interfacing systems, environmental entities.

**Finding**: Count actors in Actor Inventory tab
**Action**: Identify all actor types and document

## CR02: Interface Definition

Every actor must have documented interfaces to the system.

**Finding**: Compare actor count vs interface count
**Action**: Define interface (data/control/energy) for each actor

## CR03-CR04: Use Cases and Scenarios

3+ use cases and 2+ scenarios provide adequate operational coverage.

**Finding**: Count use cases and scenarios
**Action**: Populate Use Case Catalog and Operational Scenarios tabs

## CR05: Stakeholder Needs

5+ needs ensure requirements traceability to system context.

**Finding**: Count needs in Stakeholder Needs tab
**Action**: Interview stakeholders, document strategic/user/system/regulatory needs

## CR06: Boundary Definition

Clear boundary statement prevents scope ambiguity.

**Finding**: Check for System Boundary Definition tab and content
**Action**: Write boundary statement, define exclusions and assumptions
