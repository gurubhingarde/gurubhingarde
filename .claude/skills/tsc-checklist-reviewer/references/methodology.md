# TSC Checklist Reviewer — Methodology

Audit-ready confirmation-measures checklist for any ISO 26262 Technical Safety Concept (TSC) xlsx. Visual dashboard summary.

## Scoring

| Code | Meaning |
|------|---------|
| FC | Fully Compliant |
| LC | Largely Compliant |
| PC | Partially Compliant |
| NO | Not Compliant |
| NA | Not Applicable |
| —  | Pending reviewer |

NO on Shall = major non-conformance.

## Auto-fill confidence

- **High** — Verified directly from xlsx
- **Medium** — Inferred with caveat
- **Low** — Subjective or external (drafted)

## Source-of-truth principle

The skill never modifies the source TSC. Gaps land in Recommended Actions.
