# communication-matrix-checklist-reviewer

Run a comprehensive confirmation-measures review on any K-Matrix communication matrix xlsx workbook. Extracts ECU inventory, message catalog, signal definitions, bus allocations, and gateway routing rules, then validates against 30+ audit checks ensuring message sender uniqueness, signal ownership integrity, cross-bus routing completeness, timing feasibility, and bandwidth constraints.

## When to use this skill

Use this skill whenever the user wants to audit a K-Matrix workbook, verify cross-ECU signal coordination, check gateway routing completeness, validate bus capacity allocation, confirm message sender-receiver relationships, or prepare for regulatory submission.

## What you'll get

A detailed audit report with:
- Extracted K-Matrix structure (ECUs, messages, signals, buses)
- 30+ validation checks covering ownership, routing, timing, and capacity
- Color-coded results (pass/fail/warning) with remediation guidance
- Interactive dashboard summarizing critical findings
- Traceability matrix linking messages to ECUs and buses
- Recommendations for specification updates

## How to use it

1. Upload your K-Matrix xlsx workbook
2. Reviewer extracts all ECU, message, signal, and routing definitions
3. Automated checks validate against automotive network standards
4. Dashboard displays findings with drill-down analysis
5. Export audit report for compliance documentation
