# Requirements Allocation Checklist Methodology

## Purpose

Confirm requirements allocation matrix is complete, consistent, and ready for model-based requirements management tool import.

## Check Categories

1. **Structure**: Workbook tabs, document control
2. **Requirements**: Catalog population, hierarchical decomposition
3. **Allocation**: Coverage, consistency, target validity
4. **Relationships**: Satisfy, derive, verify, refine
5. **Coverage**: No orphans, no unallocated elements
6. **Traceability**: End-to-end paths, closure

## Workflow

1. Populate requirements catalog (system → sub-system → component)
2. Allocate each requirement to model elements
3. Define satisfy, derive, verify relationships
4. Run checklist to verify coverage
5. Resolve gaps before tool import
